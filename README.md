# Yerbangular

Este proyecto es una pagina web SPA basica en Angular.
Es sobre una empresa que vende yerba llamada YerbAngular y tiene una pagina que cubre los basicos del framework:
- Binding
- Ruteo
- Comunicacion entre componentes
- Llamados HTTP

El estilo de la pagina fue hecho con Claude, pero todo lo demas fue hecho sin IA
